# V0.1 — Foundation and CLI Scaffold

## Goal
Establish a clean, testable C++17/CMake repository with a terminal executable and persistent engineering state.

## Deliverables
- `CMakeLists.txt` requiring C++17.
- `src/main.cpp` or equivalent CLI entry point.
- `include/` and `src/` structure that can grow without a monolithic main file.
- `nova --help` and `nova --version`.
- Automated test target integrated with CTest.
- Initial README build instructions.
- State files: roadmap, phase log, verification ledger, decisions and known issues.
- `.gitignore` for build products and local experiment outputs as appropriate.

## Required behavior
- Unknown CLI arguments produce a clear usage error and non-zero exit.
- `--help` exits successfully.
- `--version` prints a stable version string.
- No unimplemented command is advertised as working.
- Project builds with C++17 and a supported CMake version discovered in the environment.

## Tests
- Unit/integration test for help.
- Unit/integration test for version.
- Unknown option returns non-zero.
- CTest discovers and runs at least one real automated test.
- Clean configure/build in a fresh build directory.

## Verification procedure
1. Inspect toolchain versions (`cmake --version`, chosen compiler version, OS).
2. Configure a clean build directory.
3. Build with the documented command.
4. Run CTest with failure output.
5. Run `nova --help`, `nova --version`, and an invalid command.
6. Save logs and exit codes under `state/evidence/`.
7. Review Git diff/status and README accuracy.

## Pass conditions
- Every required file exists.
- Clean configure and build succeed.
- CTest reports all discovered tests passing and at least one test exists.
- Help/version tests pass; invalid argument behavior is verified.
- No untracked build output is accidentally committed.
- Evidence is recorded in `state/VERIFICATION.md`.
- Roadmap status updated to COMPLETE with the exact evidence paths.

## Fail / blocked conditions
- Build/test cannot run: BLOCKED or PARTIAL.
- Empty or fake tests: fail.
- CLI help mentions future commands as available: fail.
- Build works only due to stale generated files: fail; clean build required.

## Exit gate
Do not begin V0.2 until the V0.1 pass conditions are met.
