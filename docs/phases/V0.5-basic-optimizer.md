# V0.5 — Basic TAC Optimizer

## Goal
Implement small semantics-preserving optimization passes over NOVA TAC and prove their tested behavior with unit and differential tests.

## Required passes
1. Constant folding.
2. Constant propagation.
3. Conservative algebraic simplification.
4. Dead-code elimination for pure, unobservable assignments.

Each pass must have a written precondition, rewrite rule, semantic caveat and tests. Keep passes independently callable and expose before/after TAC.

## Required tests
- Positive and negative cases per rule.
- Variables reassigned after propagation.
- Division by zero and overflow edge cases under the documented language semantics.
- Side-effecting `print` is never removed.
- Unused pure assignment can be removed.
- Optimized and unoptimized execution agree on a deterministic corpus of small programs.
- Re-running a pass reaches a fixed point or is capped with a clear termination rule.
- Optimization output is deterministic.

## Verification loop
Run per-pass unit tests; differential tests; full CTest; run example with `--show-all`; inspect IR before/after; verify no side effect was removed. If a test fails, fix implementation rather than weakening semantics.

## Pass conditions
- Every pass has isolated tests and documented semantics.
- Differential corpus passes.
- Fixed-point/termination behavior is tested.
- No mandatory test is skipped.
- Full prior test suite passes.
- Docs accurately list only implemented passes.

## Exit gate
Do not claim SmartPass novelty or begin final research conclusions based on the educational optimizer; move to benchmark baselines.
