# V1.0 — Demonstration-Ready Release

## Goal
Deliver a stable, explainable demonstration and a truthful technical report.

## Required deliverables
- Buildable repository from a clean checkout.
- Accurate README and CLI help.
- Tested NOVA Script example showing tokens/AST/TAC/optimization.
- GCC baseline and SmartPass example that can be reproduced.
- State ledger with all phases accurately marked.
- Full test report and evidence files.
- Benchmark results with raw samples and environment metadata.
- Research report and complete references.
- Known limitations and future work.

## Final release checklist
- [ ] Clean configure/build succeeds.
- [ ] All CTest tests pass.
- [ ] Sanitizer tests run where supported and their status is reported.
- [ ] NOVA Script valid/invalid examples behave as documented.
- [ ] Optimizer differential tests pass.
- [ ] SmartPass budget and correctness gates pass.
- [ ] Fixed and random search baselines exist.
- [ ] Adaptive strategy is evaluated under equal budgets.
- [ ] Holdout sizes are evaluated.
- [ ] Raw timing samples and metadata are present.
- [ ] Reports are generated from raw data.
- [ ] No unsupported claims or invented numbers.
- [ ] All references are checked.
- [ ] Every phase status is supported by evidence.
- [ ] Known issues and scope limits are visible.

## Pass conditions
Every mandatory checklist item is either completed with evidence or explicitly identified as a release blocker. A release is not `COMPLETE` if mandatory correctness, reproducibility or research-integrity checks are skipped.

## Release outcome
Use `RELEASED`, `PARTIAL_RELEASE` or `BLOCKED`; do not equate “demo runs once” with a complete research artifact.
