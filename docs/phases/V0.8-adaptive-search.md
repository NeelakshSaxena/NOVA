# V0.8 — Adaptive, Workload-Aware Search

## Goal
Implement and evaluate the proposed research contribution: use workload descriptors and prior candidate outcomes to prioritize configurations under a fixed budget.

## Deliverables
- A documented set of workload descriptors with rationale.
- A transparent candidate-priority policy.
- Persistent prior experiment data or explicitly session-local history.
- Deterministic seeds.
- Equal-budget random-search baseline.
- Ablation mode that removes workload features or prior-outcome feedback.
- Holdout input-size evaluation.
- Reports with quality-versus-budget and tuning-overhead measurements.

## Important definition
Do not call the strategy “machine learning” unless a real learned model is implemented and evaluated. A transparent heuristic is acceptable. Define exactly how features affect candidate ranking and what happens when no history exists.

## Required experiments
- Multiple benchmark families and input sizes.
- Multiple search seeds where stochasticity exists.
- Adaptive vs random under equal candidate-evaluation budgets.
- Adaptive with features vs ablation without features.
- Fixed GCC `-O2` and `-O3` baselines.
- Holdout input sizes not used for candidate selection.
- Tuning wall time and compilation overhead.
- Binary size and correctness outcomes.

## Required tests
- Feature extraction is deterministic for a fixed input.
- Missing/unknown feature values are handled explicitly.
- Search respects budget.
- Same seed and same history produce same candidate sequence.
- Search does not rank invalid candidates.
- Ablation actually removes the declared signal.
- Reports identify tuning and holdout datasets.
- No data leakage from holdout performance into candidate selection.

## Pass conditions
- Adaptive policy is implemented and documented precisely.
- Equal-budget comparisons are complete.
- At least two benchmark families are evaluated.
- Holdout evaluation is reported.
- All raw data and manifests are saved.
- Results include negative outcomes and uncertainty.
- Claims are limited to observed cases.

## Exit gate
If adaptive search does not outperform random search, do not alter the result or hide it. Analyze why, refine the hypothesis only as a new documented experiment, and report the original outcome.
