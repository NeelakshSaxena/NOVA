# V0.9 — Evaluation and Research Report

## Goal
Produce a reproducible report based only on saved raw data and traceable sources.

## Deliverables
- Experiment manifest per run.
- Scripts or documented commands to generate tables/plots from raw data.
- Methods, results, related work, limitations and threats-to-validity sections.
- Results broken down by workload and input size.
- Comparison of fixed GCC defaults, random search and adaptive search.
- Ablation results.
- Reproduction guide for a clean checkout.
- Source register with access date if required by report format.

## Required report contents
1. Research question and hypotheses.
2. Problem sourcing: what sources establish versus what is our inference.
3. System architecture and clear GCC/NOVA responsibility boundary.
4. Candidate search space and budget accounting.
5. Hardware/software environment.
6. Correctness validation method and limitations.
7. Timing protocol and raw sample count.
8. Runtime, variability, binary size and tuning overhead.
9. Equal-budget comparisons.
10. Holdout evaluation.
11. Failures, regressions and threats to validity.
12. Reproducibility instructions.
13. Related work and citations.

## Required tests
- Report-generation script runs on saved data.
- All plotted/table values can be traced to raw data.
- Missing result fields trigger warnings or errors.
- No illustrative numbers appear as measured values.
- Reproduction commands work on a clean checkout as far as the documented environment allows.
- Sources support the claims attributed to them.

## Pass conditions
- Results are reproducible from raw data.
- All hypotheses are marked supported, not supported or inconclusive based on evidence.
- No universal speedup claim.
- Limitations are explicit.
- Citations are complete and traceable.
- A reviewer can rerun the core experiment without undocumented steps.

## Exit gate
Only move to V1.0 if report and reproduction checks pass.
