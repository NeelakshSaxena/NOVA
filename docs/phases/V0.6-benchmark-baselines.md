# V0.6 — Benchmark Lab and GCC Baselines

## Goal
Establish trustworthy baseline data for selected numerical C++ workloads before implementing adaptive search.

## Initial workloads
- Matrix multiplication reference kernel.
- Vector addition.
- Add a third iterative numerical workload only after the first two have correctness tests.

## Deliverables
- Benchmark registry or documented benchmark manifest.
- Deterministic inputs and input-size controls.
- Correctness oracle/reference and documented tolerances.
- GCC `-O2` and `-O3` builds.
- Optional `-Ofast` only as a separate semantic condition.
- Repeated timing harness or documented reliable tool.
- Raw timing storage and environment manifest.
- CSV/JSON schema.

## Required metadata
OS, CPU, memory, compiler version, exact flags, source hash, input size, seed, repetitions, raw samples, median, spread, binary size and build/correctness status.

## Required tests
- Every baseline executable builds.
- Correctness tests pass.
- Deliberately incorrect output is detected by the oracle.
- Timing collector stores the configured number of samples.
- Result serialization round-trips.
- Missing metadata is detected rather than silently omitted.
- Benchmark can be rerun from a clean build.

## Verification procedure
1. Record environment.
2. Build `-O2` and `-O3` variants.
3. Run correctness tests before timing.
4. Warm up consistently if needed.
5. Run at least 9 repetitions where practical; retain all samples.
6. Report median and spread; inspect variance.
7. Interleave or randomize order if supported.
8. Repeat on at least two input sizes; reserve holdout sizes for later evaluation.
9. Save raw results and exact commands.

## Pass conditions
- Baselines are valid and repeatable enough for meaningful comparison.
- No speedup claim is made from one run or only the minimum.
- Raw timing and environment metadata are preserved.
- All correctness tests pass.
- `-Ofast` is not mixed with strict-semantics results without disclosure.
- Evidence ledger updated.

## Exit gate
Do not implement research conclusions before baseline quality is established.
