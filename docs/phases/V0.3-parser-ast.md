# V0.3 — Recursive-Descent Parser and AST

## Goal
Parse the implemented NOVA Script grammar into a typed AST, respecting expression precedence and reporting syntax errors cleanly.

## Initial grammar
```ebnf
program     = { statement } ;
statement   = "let" identifier "=" expression ";"
            | identifier "=" expression ";"
            | "print" expression ";" ;
expression  = term { ("+" | "-") term } ;
term        = unary { ("*" | "/") unary } ;
unary       = [ "-" ] primary ;
primary     = integer | identifier | "(" expression ")" ;
```
If any listed production is deferred, update the grammar and tests before claiming completion. Do not accept syntax that has no well-defined AST representation.

## Deliverables
- Recursive-descent parser.
- AST node types for Program, let/assignment/print statements and integer/variable/unary/binary expressions.
- Stable AST dump format.
- Parser diagnostics including source location and expected/actual token where practical.
- CLI command `nova ast <file>`.

## Required tests
- Single and multiple statements.
- Operator precedence: `2 + 3 * 4`.
- Left associativity: `8 - 3 - 1`.
- Parentheses override precedence.
- Unary minus if supported.
- Missing semicolon, missing operand, unmatched parentheses, unexpected EOF.
- Empty program.
- Invalid token stream.
- Parser does not hang or crash on malformed input.

## Verification loop
Run parser tests, full CTest, AST dump for valid examples and error checks for invalid fixtures. Inspect AST structure, not only printed text. Save evidence.

## Pass conditions
- All grammar productions are tested.
- AST structure reflects precedence/associativity.
- Errors are deterministic, location-aware and non-crashing.
- Full prior test suite passes.
- Grammar documentation matches parser behavior exactly.

## Exit gate
No semantic analysis until this gate passes.
